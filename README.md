### ▸ Pesquisa atual

**[Detecção de exfiltração e dados sensíveis com IA (PIBITI)](https://github.com/JorgeVieirah/pibiti-pibid-osc)**
Protótipo open source que combina um **Autoencoder** (anomalias no tráfego de rede) com **NLP / BERTimbau** (dados pessoais em payloads) para ajudar organizações da sociedade civil de Manaus a cumprir a LGPD.

```
.pcap ──► features (scapy) ──► autoencoder ──► score de anomalia ──┐
                                                                   ├──► alerta (LGPD)
payload ──► regex + NLP (BERTimbau) ──► dados pessoais ────────────┘
```
